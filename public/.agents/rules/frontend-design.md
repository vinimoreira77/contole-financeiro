# Frontend Design Guidelines

Ao trabalhar em arquivos HTML/CSS/JS de interface, siga rigorosamente estes princípios:
1. **Estética Premium**: Priorize designs modernos e limpos. Evite cores genéricas (vermelho puro, azul puro); use paletas harmoniosas, "dark modes" elegantes e elementos como *glassmorphism* se couber.
2. **Micro-interações e Dinamismo**: A interface deve parecer "viva". Sempre adicione efeitos de `hover`, transições suaves (`transition: all 0.3s ease`) e animações sutis.
3. **Tipografia Moderna**: Não utilize fontes padrão do navegador. Dê preferência a fontes modernas (como Inter, Roboto, Outfit).
4. **Responsividade**: O layout deve ser fluido. Use Flexbox/Grid e garanta que a interface funcione perfeitamente do celular ao desktop.
5. **Sem Placeholders**: Nunca deixe imagens quebradas ou textos de marcação sem um visual agradável. Se precisar, sugira a geração de imagens reais.
